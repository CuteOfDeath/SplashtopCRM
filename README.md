# Installation:
Pull the source code from the repository, and then follow the usual react vite build process.

Download the [CRMServer Depository](https://github.com/CuteOfDeath/SplashtopCRMServer) and put it in a folder named "crmapi" in the same directory as the app (if you wish, dashboard.tsx contains a variable where you may change the api directory name)

Update the credentials.txt with your hostname, dbname, username and password.

You're done!

This was made with Apache and MySQL.
It is unknown to me if it is possible to host this in any other way.
